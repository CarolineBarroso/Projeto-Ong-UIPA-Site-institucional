## Sobre o projeto

Este projeto consiste no desenvolvimento de um site institucional com o tema da UIPA – União Internacional Protetora dos Animais. O objetivo é apresentar informações sobre a causa animal, destacar a importância da proteção e do cuidado com os animais e disponibilizar uma página de contato para os visitantes.
O site foi desenvolvido como atividade acadêmica, com o propósito de aplicar conhecimentos básicos de desenvolvimento web utilizando HTML, CSS e JavaScript.

> Importante: Este site é um protótipo acadêmico e não representa o site oficial da UIPA.

## Objetivos do projeto

* Desenvolver um site institucional com navegação simples.
* Apresentar informações sobre a proteção animal.
* Organizar o conteúdo em páginas diferentes.
* Aplicar conhecimentos de HTML, CSS e JavaScript.
* Desenvolver uma interface responsiva.
* Praticar a organização de arquivos e pastas.

## Tecnologias utilizadas

* HTML5: estruturação do conteúdo das páginas.
* CSS3: estilização, cores, espaçamentos e responsividade.
* JavaScript: implementação de interações e validações.

## Descrição dos arquivos
- [index.html]	Página inicial

## Páginas desenvolvidas

* Página inicial
Apresenta a identidade visual do site, uma mensagem sobre o cuidado com os animais, menu de navegação, imagem de destaque, botões de acesso, cards informativos e rodapé.

* Página Sobre
Apresenta informações relacionadas à causa animal, história e contexto, missão, público atendido e compromisso com a proteção dos animais.

* Página Projetos
Apresenta três exemplos didáticos de iniciativas:

* Proteção e cuidado.
* Adoção responsável.
* Educação e conscientização.

Observação: Os exemplos são ilustrativos e foram desenvolvidos para fins acadêmicos. Não representam necessariamente projetos oficiais da UIPA.

* Página Contato
Disponibiliza um formulário com os campos:

* Nome.
* E-mail.
* Assunto.
* Mensagem.

Após o preenchimento, o JavaScript realiza verificações e apresenta uma mensagem de confirmação.

Observação: O formulário é demonstrativo, não envia mensagens para a instituição e não armazena os dados preenchidos.

## Responsividade

O projeto utiliza recursos do CSS para adaptar a apresentação do conteúdo a diferentes dispositivos, como computadores, tablets e celulares. Foi utilizado o recurso @media para modificar determinados estilos conforme a largura da tela.

## Como executar o projeto

1. Baixe ou extraia a pasta do projeto.
2. Localize o arquivo index.html.
3. Abra o arquivo em um navegador, como Google Chrome, Microsoft Edge ou Firefox.
4. Utilize o menu para navegar entre as páginas.

Não é necessário instalar programas adicionais para visualizar a versão demonstrativa.
